# Zero Space · Telegram-бот v0.3

**Clean. Create. Continue the story.**

Личный бот на русском: реальные задачи по уборке, искры, мягкое растворение хаоса и обустройство комнаты енота-писателя Реда.

## Что уже работает

- Добавление задачи обычным текстом или кнопкой «Добавить дело».
- Четыре уровня сложности: совсем легко / Easy — 1, легко / Easy — 3, средне / Medium — 7, сложно / Hard — 12 искр.
- Изменение названия и сложности до выполнения, архивирование ненужной задачи с подтверждением.
- Выполнение задачи, однократное начисление искр, «О дивный чистый мир» — история полученных наград: сколько искр и за какое дело. Записи идут от новых к старым; есть общая сумма заработанных искр. Покупки не удаляют награды из истории. Уже выполненные задачи автоматически отображаются в ней.
- Список активных дел с перелистыванием и сортировкой от 1 искры к 12.
- Выполненную по ошибке задачу можно вернуть: награда и очищенный хаос откатываются, но купленная мебель и этап комнаты остаются. Если искры уже потрачены, новые награды сначала компенсируют возврат — повторно получать одни и те же искры не получится.
- Постоянно доступный переключатель Русский / English. Меню, комната, история, покупки и будущие сообщения используют выбранный язык; пользовательские названия задач не переводятся.
- В комнате живёт мягкий чернильно-чёрный клубок тумана — визуальный хаос без страшных или демонических деталей.
- После выполнения задачи бот присылает чёткое полноразмерное изображение комнаты с уже уменьшившимся облаком хаоса. Это сохраняет качество деталей и быстрее работает на телефоне.
- Комната на каждом изображении постепенно становится светлее по мере уменьшения хаоса.
- Комната с четырьмя этапами: пустая, первый уют, окно со шторами, готовый писательский интерьер.
- Покупки за искры: ковёр и растение — 18; окно и шторы — 53; обои, дверь и писательский уголок (кресло, стол, книги) — 95.
- Каждый набор мебели становится доступен, когда реальные дела рассеяли соответствующий участок хаоса: после 18, 71 и 166 суммарно заработанных искр. Покупка тратит текущий баланс, но очищенный хаос и история наград не возвращаются.
- Сохранение задач, искр, покупок, незаконченного ввода и привязки владельца в SQLite.
- Только личный чат с владельцем. Группы не обслуживаются. Штрафов и ежедневных серий нет.

Это версия обычного Telegram-бота с фото комнаты и кнопками под сообщениями. Фото можно раскрыть на весь экран. Отдельного полноэкранного Mini App, таймеров, напоминаний, календаря и других персонажей в этой версии нет. Изображения — художественные иллюстрации этапов, их детали могут немного отличаться между сценами.

## Запуск на компьютере

Потребуется Python 3.11 или новее и интернет с доступом к api.telegram.org.

1. Распакуй архив. Открой терминал в папке `zero-space-bot`.
2. В Telegram открой официальный [BotFather](https://t.me/BotFather), отправь `/newbot`, задай имя и свободный username с окончанием `bot`.
3. Установи библиотеку для изображений: `python -m pip install -r requirements.txt`.
4. Выполни `python setup.py`. На macOS/Linux команда может называться `python3`; в Windows можно использовать `py`.
5. Вставь токен в скрытое поле терминала. Программа проверит токен и сохранит `.env`. Не публикуй этот файл.
6. Выполни `python bot.py` (или `python3 bot.py` / `py bot.py`).
7. Открой личную ссылку, которую показал setup, и нажми «Запустить». Первый вход по ней привяжет бота к твоему аккаунту. После привязки другие аккаунты не смогут пользоваться им даже с этой ссылкой.
8. Напиши «Разобрать полку» → выбери сложность → когда сделаешь, нажми «Готово». Бот покажет комнату с уменьшившимся хаосом.

Если терминал закрыть или компьютер выключить, бот перестанет отвечать до следующего запуска. Данные останутся. Для постоянной работы нужен включённый компьютер или сервер. Телефон используется для общения с ботом; запуск Python на iPhone не предполагается.

Если личная ссылка потерялась до привязки, она имеет вид `https://t.me/ИМЯ_БОТА?start=PAIRING_CODE`, где PAIRING_CODE берётся из локального `.env`. Код не является токеном бота, но до привязки тоже должен оставаться личным.

## Постоянный запуск с Docker

После `python setup.py` на компьютере или сервере с Docker Compose:

```sh
docker compose up -d --build
docker compose logs -f
```

Остановка: `docker compose down`. База лежит в `data/domik.sqlite3` и сохраняется между пересозданиями контейнера. Не запускай одновременно `python bot.py` и контейнер с тем же токеном.

Для переноса или резервной копии сначала останови бота, затем скопируй всю папку `data` и `.env` в безопасное место. Новая пустая база утратит привязку владельца; при переносе обязательно переноси базу. Смена токена требует очистить только ключи `photo:*` из таблицы `meta`, если меняется сам бот: устаревшие photo ID также автоматически заменяются после ответа Telegram 400.

## Проверка

```sh
python -m unittest discover -s tests -v
```

Тесты работают без сети и без токена. Живое подключение нужно проверить после ввода собственного токена: создание задачи, изменение сложности, выполнение, покупка, перезапуск и доступ с другого аккаунта.

## Устройство проекта

- `bot.py`: Telegram API, обработчики, игровая логика, личный доступ и SQLite.
- `media.py`: качественная композиция комнаты с меняющимся облаком хаоса.
- `setup.py`: локальное подключение токена и создание ссылки привязки.
- `assets/`: четыре изображения комнаты и прозрачный клубок хаоса.
- `tests/`: проверки наград, покупок, доступа и сохранения данных.
- `compose.yaml`, `Dockerfile`: постоянный запуск.

Используется long polling через официальный [Telegram Bot API](https://core.telegram.org/bots/api#getupdates). Публичный сайт, HTTPS-домен и webhook не нужны. Существующий webhook бот не удаляет автоматически. Секреты и содержимое задач не пишутся в журнал.

## Ограничения v0.2

Один владелец, один процесс бота, одна SQLite-база. Завершение, возврат задач и покупки защищены от повторного начисления/списания. Изображение создаётся при первом сочетании этапа и прогресса, затем хранится в `data/media_cache`. Telegram не позволяет надёжно перевести всю уже отправленную переписку разом: после смены языка ранее созданные экраны переводятся при повторном открытии. При сбое сети баланс и хаос не изменятся второй раз. Дополнительные предметы, свободная расстановка мебели, даты и напоминания — следующие версии.
