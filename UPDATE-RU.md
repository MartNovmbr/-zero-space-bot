# Zero Space v1 — обновление с жемчужиной

Это обновление существующего бота @Zero_place_bot. Красивый интерфейс открывается внутри Telegram как Mini App. Токен бота менять не нужно.

## Что изменилось

- Согласованный тёмно-серый экран с жемчужиной, состояния нитей, Сегодня / Задачи / История.
- Без искр, сложности, магазина и перетаскивания.
- «Карандаш» у каждой активной задачи открывает форму изменения текста и категории.
- При создании и редактировании есть большое поле, ограничение 40 символов и счётчик. Сервер тоже проверяет длину.
- Создание, редактирование и выполнение оставляют тебя на вкладке «Задачи».
- Выполненную задачу можно вернуть из Истории. Очистка истории обнуляет выполненную часть шкалы; открытые задачи остаются.
- Порядок категорий: Спальня, Ванная, Прихожая, Кухня, Балкон, Продажа, ЖКХ, Финансы, Покупки, Документы.

## Важно про сброс

При первом успешном запуске этой версии старые задачи, история, искры и обустройство удаляются из используемой базы. Сброс разрешён тобой и запускается автоматически один раз. Повторный запуск уже не удалит новые задачи. Сохраняются владелец, настройка языка и позиция чтения Telegram. Интерфейс этой версии русский.

На действующем сервере сброс ещё не выполнен — он произойдёт после установки. Старые сообщения и фотографии в переписке Telegram останутся: удаление данных бота не удаляет переписку. Старые кнопки предложат открыть новое приложение.

## Установка с iPhone или компьютера

1. Скачай ZIP и распакуй его (на iPhone нажми архив в приложении «Файлы»). Внутри папка `zero-space-update-v1`.
2. Открой https://github.com/MartNovmbr/-zero-space-bot на вкладке Code, ветка main. Это корень репозитория — экран со списком bot.py, Dockerfile и других файлов.
3. Выбери Add file → Upload files (на узком экране пункт может находиться под «…»). Загрузи **содержимое** распакованной папки на этот уровень: `app.html`, `app_server.py`, `bot.py`, `media.py`, `setup.py`, `requirements.txt`, `Dockerfile`, `test_update.py`, `UPDATE-RU.md`. Не загружай ZIP или папку целиком как вложенный каталог. Подтверди Commit changes. Папку assets и старые файлы удалять не нужно.
4. В Railway открой существующий проект → сервис `-zero-space-bot`. Если сборка началась сразу, отсутствие домена может временно остановить запуск — настрой следующие пункты.
5. В Settings → Networking → Public Networking нажми **Generate Domain**. Если спросит порт, укажи **8080**. Если домен уже есть, используй его. Получится адрес вида `https://...up.railway.app`.
6. В Variables сохрани существующие `BOT_TOKEN`, `ALLOWED_USER_ID` (если есть), `PAIRING_CODE` (если есть) и `DATABASE_PATH`. Добавь `APP_URL` = полный HTTPS-адрес из шага 5, без добавочного пути. Добавь `PORT` = `8080`.
7. Проверь постоянное хранилище: SQLite должна находиться на подключённом Railway Volume. Если он уже подключён, **сохрани прежний путь DATABASE_PATH и точку монтирования**. Если хранилища нет, подключи Volume с Mount Path `/app/data`, задай `DATABASE_PATH=/app/data/domik.sqlite3` и обязательно задай `ALLOWED_USER_ID` своим числовым Telegram ID: новая база не знает владельца. Не вводи туда @имя бота. Без Volume данные могут потеряться при следующем развёртывании.
8. В Settings → Deploy проверь Start Command: `python app_server.py`. Новый Dockerfile использует эту команду по умолчанию. Старое значение `python bot.py` тоже перенаправлено в новую версию. Должна работать **одна реплика** сервиса.
9. Примени изменения Variables кнопкой Deploy / Apply changes. Если обновление не началось, в Deployments выбери Redeploy последнего развёртывания. Дождись Running / Active; в журнале появится `Zero Space v1 ready`.
10. Открой @Zero_place_bot, отправь `/start` и нажми **Открыть**. Интерфейс появится внутри Telegram. Кнопка «Открыть» также появится у поля ввода. Если владелец ранее не был привязан и используется PAIRING_CODE, сначала открой прежнюю личную ссылку привязки.

## Быстрая проверка после запуска

1. На Сегодня нет задач и баллов, показана жемчужина.
2. Создай «Протереть зеркало», выбери «Ванная»: откроется вкладка Задачи.
3. Нажми «Карандаш», измени текст и категорию. Сохрани — изменения должны остаться после закрытия и повторного открытия приложения.
4. Попробуй ввести больше 40 символов: счётчик показывает предел, лишний ввод ограничивается.
5. Выполни задачу, верни её из Истории, затем проверь экран Сегодня.

Если мини-приложение не открывается: APP_URL должен начинаться с https://, домен должен вести в этот сервис на порт 8080. Если пишет «Это личный бот», проверь свой ALLOWED_USER_ID и что используешь прежнюю базу. Если сессия истекла — закрой и открой приложение кнопкой в боте.

## Проверки сборки

`python -m unittest -v test_update.py`

Проверяются одноразовый сброс, сохранение владельца, редактирование, длина и категория, выполнение/возврат, очистка истории, повтор запросов и подпись Telegram. Живое подключение с твоим токеном проверяется только после установки в Railway.

Официальные справки: https://core.telegram.org/bots/webapps и https://docs.railway.com/networking/public-networking
